# asciixmas

A looping ASCII Christmas scene in a single HTML file.

A strand spells out *O Christmas Tree* as it winds up into a turning fir lettered with Christmas words. Fairy lights, glass baubles and the star come on, and presents drop in with a cartoon bounce. Then a dachshund in a Santa hat trots up, a snowflake lands on its nose, and it sneezes, shaking snow off the tree onto its hat.

## Run it

Open `index.html` in a browser. There's no build step and nothing to install.

## Controls

- **Space** or **K**: pause / play (or click the scene)
- **R**: replay from the start

If your system asks for reduced motion, the scene holds still on the moment the flake lands on the dog's nose.
